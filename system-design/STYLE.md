# FaroDocs diagram style

These planning diagrams use an original project palette. The warm paper direction is informed by the local AI Engineering visual guide; no reference diagram, logo, asset, layout, or component is reused. These tokens describe diagrams only. Product UI tokens will be decided during the frontend slice.

| Role | Value | Use |
| --- | --- | --- |
| Paper | `#F7F3EA` | Canvas |
| Surface | `#FFFEFB` | Component cards |
| Ink | `#17263D` | Titles and primary labels |
| Muted | `#526176` | Descriptions and connectors |
| Rule | `#C9D0D5` | Borders |
| Accent | `#A84128` | One focal stage per view |
| Accent wash | `#F3DFD6` | Focal stage background |
| Data wash | `#E9EFF1` | Storage cards |

All figures are static, use system fonts, and contain text alternatives in SVG `title` and `desc` elements. A status line identifies them as proposed architecture.
